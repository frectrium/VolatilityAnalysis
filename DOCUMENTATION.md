# Volatility Analysis Pipeline — Documentation

## Overview

This pipeline predicts the implied volatility surface (IVS) of S&P 500 index options one day ahead, with calibrated uncertainty estimates. It extends the two-step framework of Zhang et al. (2021) by replacing LSTM with a Bayesian Neural Network for uncertainty quantification.

**Pipeline stages:**

| Stage | Module | Description | Output |
|-------|--------|-------------|--------|
| 1 | `pipeline_part1_preprocessing.py` | Load raw data, filter, interpolate term structure | `surface_dict` |
| 2 | `pipeline_part2_moussa_filter.py` | Moussa (2025) arbitrage filtering | `filtered_dict` |
| 3 | `pipeline_part3_isnn.py` | ISNN-2 per-date surface fitting | Per-date models |
| 4 | `pipeline_part4_surface_sampling.py` | Evaluate ISNN on grid, invert BS for IV | `iv_matrix (n_dates, 154)` |
| 5 | `pipeline_part5_vae.py` | VAE compression to latent factors | `latent_factors (n_dates, 5)` |
| 6 | `pipeline_part6_bnn.py` | BNN prediction of next-day latent factors | Predictions + uncertainty |

## Quick Start

```bash
# Activate environment
conda activate finance

# Run full pipeline (all dates, ~hours)

# Quick test (20 dates, ~minutes)

python main_pipeline.py --stage 6 --test_year 2016 --bnn_epochs 1000
```

## Stage Details

### Stage 1: Preprocessing

**Input:** Raw CSV files (op_df, fwd_df, discount_df, St_df)

**Processing:**
1. Filter to call options only (`cp_flag == 'C'`)
2. Compute maturity in days: `exdate - date`
3. Interpolate forward prices and discount factors at each contract's maturity using the 8-tenor grid (0, 7, 14, 30, 60, 90, 180, 350 days) with clamped boundary extrapolation
4. Compute mid-price `(bid + offer) / 2`, bid-ask spread
5. Drop invalid rows: `offer <= bid`, zero maturity
6. Volume filter (default: >= 10 contracts)
7. Aggregate duplicate contracts by (date, exdate, strike)
8. Group by date into `surface_dict`

**Output:** `Dict[Timestamp -> DataFrame]` with columns: date, exdate, strike, volume, spread, bid, offer, fwd_price, discount, maturity_days, Spot, midP, spread_rel

**Key parameters:** `--min_volume` (default: 10)

---

### Stage 2: Moussa Arbitrage Filter

**Reference:** Moussa, K. (2025) "Arbitrage Filtering of Option Prices"

**Algorithm:** For each date, for each expiry:
1. Normalize prices: `K_norm = K/F(T)`, `C_norm = C / (B(T)*F(T))`
2. Sort quotes by liquidity proxy: `volume / (|K_norm - 1| + 0.01)`
3. Iteratively build an arbitrage-free set by checking monotonicity and convexity bounds
4. Accepted quotes are within bounds; rejected quotes are adjusted

**Output:** Same as input with added columns: `K_norm`, `C_norm`, `moussa_C_norm`, `moussa_price`, `is_changed`

**Key parameters:** `--lambda_param` (default: 0.01, controls adjustment strength)

---

### Stage 3: ISNN-2 Surface Fitting

**Reference:** Jadoon et al. (2025) "Input Specific Neural Networks" (arXiv:2503.00268v1)

**Architecture:** Two-branch neural network that structurally enforces:
- **Convexity in strike** via non-negative weight constraints on propagation layers
- **Monotonicity in time** via non-negative time-branch weights
- **Softplus activation** (log(1 + exp(x))) — convex and monotone

```
Input:  x0 = K/F (moneyness)     -> Convex branch
        t0 = T/365 (time)        -> Monotonic branch

Convex branch:  z_1 = softplus(x0 * W_xx0 + t0 * W_xt0 + b)
                z_h = softplus(z_{h-1} * W_xx[+] + x0 * W_xx0 + t_h * W_xt[+] + b)
Output:         C_norm = z_H * W_out[+]    (no activation)

[+] = non-negative weight constraint
```

**Training:** One model per date, MSE loss, Adam optimizer, ReduceLROnPlateau scheduler. Weights projected after each step to maintain non-negativity.

**Output:** Per-date `.pt` checkpoint files with state_dict, losses, hyperparams

**Key parameters:** `--epochs` (2000), `--lr` (0.005), `--hidden_dim` (128), `--num_layers` (3), `--max_dates`

---

### Stage 4: Surface Sampling & IV Inversion

**Grid (matching Zhang et al. 2021):**
- 14 moneyness points: K/F in {0.6, 0.8, 0.9, 0.95, 0.975, 1.0, 1.025, 1.05, 1.1, 1.2, 1.3, 1.5, 1.75, 2.0}
- 11 maturity tenors: {10, 30, 60, 91, 122, 152, 182, 273, 365, 547, 730} days
- Total: 154 grid points per day

**Procedure:**
1. Evaluate ISNN at each grid point: `C_norm = model(K/F, T/365)`
2. Clamp to valid BS range: `max(0, 1-K/F) < C_norm < 1`
3. Invert Black-Scholes using vectorized Newton-Raphson:
   - Normalized BS formula: `C_norm = N(d1) - (K/F)*N(d2)`
   - Newton update: `sigma -= (C_model - C_target) / vega`
   - Converges in ~10 iterations to machine precision
4. Brentq fallback for edge cases (deep OTM/ITM)
5. Grid-based NaN interpolation for remaining failures

**Key insight:** The ISNN's C_norm directly equals the normalized BS formula, so no forward/discount lookup is needed for the inversion.

**Output:** `iv_matrix` shape (n_dates, 154), `dates` list

---

### Stage 5: Variational Autoencoder

**Reference:** Kingma & Welling (2013); Zhang et al. (2021) Section 3.1 Method 3

**Architecture:**
```
Encoder:  154 -> 128 (ReLU) -> 128 (ReLU) -> 128 (ReLU) -> mu(5), logvar(5)
Decoder:  5 -> 128 (ReLU) -> 128 (ReLU) -> 128 (ReLU) -> 154 (no activation)
```

**Training:**
- Input standardization: zero mean, unit variance per feature (StandardScaler)
- Loss: `MSE + beta * KL`, with beta warmup (0 -> target over first 20% of epochs)
- Random 85/15 train/val split, early stopping
- Adam optimizer, ReduceLROnPlateau

**Latent factor extraction:** Deterministic — uses encoder mean `mu(x)` only (no sampling)

**Output:** `latent_factors` shape (n_dates, latent_dim), trained VAE, scaler

**Key parameters:** `--latent_dim` (5), `--vae_beta` (0.1), `--vae_epochs` (500), `--vae_hidden_dim` (128)

---

### Stage 6: Bayesian Neural Network

**Novel contribution:** Replaces LSTM from Zhang et al. (2021) with BNN for calibrated uncertainty.

**Architecture (Bayes by Backprop):**
```
Input:  [z_t (5), S_t (1), F_t at 8 tenors (8)] = 14 dims
Hidden: 64 (ReLU) -> 64 (ReLU) -> 64 (ReLU)
Output: z_{t+1} (5 dims)
```

Each weight has a Gaussian distribution: `w ~ N(mu, sigma^2)` where `sigma = log(1+exp(rho))`.

**Local reparameterization trick:** Instead of sampling weights, sample pre-activations directly:
```
act_mu  = x @ weight_mu.T + bias_mu
act_var = x^2 @ weight_sigma^2.T + bias_sigma^2
act     = act_mu + sqrt(act_var) * eps,  eps ~ N(0,1)
```
This reduces gradient variance compared to naive weight sampling.

**Loss (ELBO):**
```
L = E[MSE(y_pred, y_true)] + (1/N_train) * KL(q(w) || p(w))
```
where KL is between the variational posterior q and a Gaussian prior N(0, prior_sigma^2).

**Prediction:**
1. Run 200 Monte Carlo forward passes (stochastic weights)
2. Compute mean and std of latent factor predictions
3. Pass each sample through VAE decoder
4. Inverse-transform through StandardScaler
5. Result: 154-point IV surface with uncertainty bands

**Data split:** Temporal — Train: up to test_year-2, Val: test_year-1, Test: test_year onwards

**Output:** Predictions dict with `latent_mean`, `latent_std`, `iv_mean`, `iv_std`, `iv_samples`; metrics including RMSE and CI coverage

**Key parameters:** `--bnn_epochs` (500), `--bnn_hidden_dim` (64), `--bnn_prior_sigma` (1.0), `--bnn_mc_samples` (200), `--test_year` (2019)

## Running Individual Stages

The `--stage` argument lets you run specific stages while loading saved outputs from previous stages:

```bash
# Re-run just the VAE with different beta
python main_pipeline.py --stage 5 --vae_beta 0.01 --vae_epochs 1000

# Re-run BNN with different settings
python main_pipeline.py --stage 6 --test_year 2016 --bnn_epochs 1000

# Re-run stages 4-6 (e.g., after changing grid)
python main_pipeline.py --stage 4 5 6

# Run everything from scratch
python main_pipeline.py --max_dates 100
```

**Dependency chain:**
```
Stage 1 -> Stage 2 -> Stage 3 -> Stage 4 -> Stage 5 -> Stage 6
                                                  |          |
                                          Stage 1 (market_data) -+
```

Each stage loads its dependencies from `outputs/stageN/` if they aren't passed in-memory. You must have run all prerequisite stages at least once before running a later stage independently.

## Key Hyperparameters & Tuning Guide

### Stage 3 (ISNN)
| Parameter | Default | Notes |
|-----------|---------|-------|
| `--epochs` | 2000 | More epochs = better fit but slower. Monitor loss convergence. |
| `--hidden_dim` | 128 | Larger = more expressive but ~O(dim^2) parameters. |
| `--max_dates` | None | Set to 20-50 for quick testing. |

### Stage 5 (VAE)
| Parameter | Default | Notes |
|-----------|---------|-------|
| `--latent_dim` | 5 | Core parameter. 3-10 reasonable. Lower = more compressed. |
| `--vae_beta` | 0.1 | KL weight. Lower = better reconstruction, less regularized latent space. Try 0.01-1.0. |
| `--vae_epochs` | 500 | Usually converges in 100-300 with early stopping. |

### Stage 6 (BNN)
| Parameter | Default | Notes |
|-----------|---------|-------|
| `--bnn_prior_sigma` | 1.0 | Wider prior = more uncertainty. Try 0.1-5.0. |
| `--bnn_mc_samples` | 200 | More = smoother uncertainty estimates. 100-500 reasonable. |
| `--test_year` | 2019 | Must be within your data range. Val = test_year-1. |
